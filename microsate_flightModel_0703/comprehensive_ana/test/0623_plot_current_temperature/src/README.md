# kx12 探路者 遥测数据可视化
基于 Python（pandas + matplotlib）完成 kx12 VLAST 探路者遥测时序可视化，图表统一采用地面时间为横轴，单次执行可输出 2 类工程曲线。

## 目录结构
```
0623/
├── data/                     # 原始遥测文件（csv / xlsx）
├── src/
│   ├── telemetry_lib.py      # 绘图核心逻辑，由入口脚本调用，不可独立运行
│   ├── plot_workTime.py      # 入口脚本：workTime 工作时段模式
│   ├── plot_dots.py          # 入口脚本：dots 断点模式
│   └── plot_connect.py       # 入口脚本：connect 断点模式
└── result/                   # 图表输出目录，运行代码自动生成
```

## 环境依赖
```
pip install pandas matplotlib openpyxl
```
openpyxl 用于解析遥测包4的 xlsx 文件。

## 运行方式
VSCode 打开 `src` 目录下任意入口脚本，点击右上角运行按钮即可执行。
不同入口脚本对应不同断点绘制模式，输出文件自带区分后缀，不存在覆盖冲突。
图表统一保存至 `result`，命名格式示例：`遥测包3_径迹CsI_workTime.png`。

## 输出 2 类图表
| 图表名称 | 数据源 | 展示内容 |
|----|----------|------|
| 遥测包3 · 径迹CsI | 遥测包3 | 3路电源电流、4路FEE温度 |
| 遥测包4 · 量能器FEE | 遥测包4(xlsx) | FEE1~4 电源电流点1/2与温度，各FEE独立纵轴 |

## 断点模式（GAP_MODE）
设备关机时段会填充无效温度占位值，程序识别后做空缺处理，共三种绘制方案：
- workTime：关机区间曲线断开留白
- dots：仅绘制离散数据点，不生成连线
- connect：剔除无效值后连续连线，曲线跨关机时段

三种模式使用同一套数据源、数值阈值与监测通道，仅空缺区间绘制逻辑存在差异。

## 可调参数（`telemetry_lib.py` 文件头部）
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `CSI_CURRENT_VALID` | `(50, 440)` | 径迹 CsI 电流有效区间与纵轴范围 |
| `CALO_CURRENT_VALID` | `(50, 1400)` | 量能器电流有效区间与纵轴范围 |
| `TEMP_VALID` | `(15, 45)` | 温度有效区间(℃)与纵轴范围 |
| `GAP_MODE` | `"workTime"` | 断点绘制模式，由入口脚本配置，无需手动修改 |

## 数据处理规则
1. 高低位解析：部分遥测数据分为状态位 `[15:12]` 与有效数据位 `[11:0]`，程序统一截取 `[11:0]` 作为物理测量值。
2. 无效值过滤：关机占位温度（−273.15、1e8、−3960等）超出阈值后转为 NaN，绘图阶段自动断开不渲染。
3. 量能器 FEE1：电流/温度 raw 取 `[11:0]`；电流换算 mA（监测点1/0.01，监测点2/0.125）；温度按公式 `tempx=cur*2500/4096` 再代入文档公式得 ℃。FEE2~4 电流/温度直接读 `data[11:0]`，不做换算。
4. 量能器电流仅绘制监测点1、监测点2，不绘制监测点3。
5. 表头兼容：同一物理量在不同数据包中列名不统一，内置 `pick()` 函数自动匹配有效列读取数据。
